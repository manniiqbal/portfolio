Overview

Built a computer vision pipeline for AI-assisted chest X-ray triage. Rather than attempting an autonomous medical diagnosis, the system ranks scans by pneumonia-related risk so higher-risk cases can be prioritised for review.

The pipeline handles raw DICOM images, performs medical-image preprocessing, fine-tunes a pretrained ResNet18, applies a sensitivity-optimised decision threshold, and uses Grad-CAM to visualise regions that influenced individual predictions.

Triage ≠ diagnosis

This research prototype prioritises a review queue. It is not clinically validated and does not make autonomous diagnoses.

04

Modelling

BackboneResNet18

ImageNet-pretrained with its classifier replaced by a single binary output. The full network was fine-tuned.

OptimisationAdam · 1e−4

BCEWithLogitsLoss with a 3.29 positive-class weight to address class imbalance.

SelectionBest of 10

The checkpoint with the lowest validation loss was retained, rather than the final epoch.

Best checkpoint / epoch 2

0.6800validation loss 0.8794validation ROC-AUC

Why epoch 2?

Validation performance stopped improving after the first few epochs while training accuracy kept rising, eventually reaching 94.8%. This divergence indicated overfitting, so the best validation checkpoint was restored.

09

Limitations

What this system
does not claim

  • 01

    Sigmoid outputs are model risk scores, not calibrated clinical probabilities.

  • 02

    This version uses an image-level split. PatientID metadata was effectively unique per scan, so future work should recover reliable source identifiers and enforce patient-level splitting.

  • 03

    Grad-CAM does not prove that highlighted regions correspond to true pathology.

  • 04

    This is a research and portfolio decision-support prototype—not clinically validated software and not intended for autonomous diagnosis.
