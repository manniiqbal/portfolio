# Mustafa Iqbal — Portfolio

A responsive, accessible personal portfolio built with HTML, CSS, and JavaScript.

## Run locally

No installation or build step is required.

- Open `index.html` directly in a browser, or
- From this folder, run `python -m http.server 8000`, then visit `http://localhost:8000`.

## Customise

- Edit page content in `index.html`.
- Adjust colours and layout in `styles.css`.
- Add project cards inside the `#work` section as your portfolio grows.
